### P0-4 检索溯源弹窗（`TraceDialog.vue`）

**触发**：提问后默认弹开，SSE `step` 事件逐步点亮；可关闭（×）。

**结构**：
- 标题「知识检索与图谱溯源」
- 顶部**5 步流程条**：📝问句理解 → 🔍多路检索 → 🔄证据融合 → 📊相关性排序 → ✓生成回答（已完成=绿，当前=橙 `#f59e0b`，待执行=灰）
- 各步详情：
  - **步骤1 问句理解**：原始问题 vs 改写后查询（左右对比）。截图示例：`四君子汤由哪些中药组成？` → `四君子汤的中药组成成分`
  - **步骤2-3 多路检索 / 证据融合**：4 张数字卡 —— 向量检索（语义相似度）0 / 中医药图谱（1个命中实体）22 / 关键词检索（关键词匹配）0 / → 证据融合（互惠排名融合）0
  - **步骤4 相关性精排**：N 条证据进入回答上下文 + 状态徽章「证据充分，正常生成」（绿色胶囊）
- （扩充，符合合并方案）「自反思」触发时显示一轮「重查」提示；Agent 调用了哪些工具展示在该步数字卡/说明内。

**验收**：① 5 步依次点亮；② 四君子汤问题命中面板复现「22/0/0」；③ SSE 事件到哪步点亮到哪步。

### P0-5 本草图谱 —— 图谱浏览 & 候选审核（`GraphExplore.vue` / `CandidateReview.vue`）

**布局**：全局侧栏 + 顶栏；主内容三栏：左实体列表(约 250px) + 中图谱画布(flex)+ 右详情面板(约 280px)。

**顶部操作栏**：面包屑「知识工作台 / 本草图谱」；Tab「图谱浏览」|「候选审核」（当前激活）；搜索框 placeholder「搜索中药、方剂、证候或症状」+ 下拉「全部实体类型」+ 绿色主按钮「查询」+ 文字按钮「重新导入基础数据」。

**左栏实体列表**：标题「实体结果」+ 数量徽标（如「50」）；筛选项含彩色圆点 + 实体名 + 类型标签（中药/症状/功效…）+ 右箭头；选中项高亮（浅绿背景）。样例实体：人参(中药 highlighted)、便溏(症状)、健忘(症状)、养血安神(功效)、养阴益胃生津(功效)、冰糖/北沙参(中药)、发热重微恶风/口渴/口燥咽干(症状)。

**中栏图谱画布（ECharts force 布局）**：
- 节点类型与颜色（6 类）：方剂 `#2d6a4f` / 中药 `#52b788` / 证候 `#bc6c25` / 症状 `#dda15e` / 功效 `#74c69d` / 禁忌 `#c62828`；节点大小区分层级。
- 边标注关系：组成 / 主治 / 功效 / 禁忌 等。
- 节点样例：方剂 四君子汤 / 归脾汤 / 酸枣仁汤；中药 人参/白术/黄芪/当归/茯苓/炙甘草/远志/龙眼肉/木香/冰糖/北沙参；证候 脾气虚/心脾两虚；功效 益气健脾/益气补血健脾养心/养血安神/养阴益胃生津；禁忌 对方剂成分过敏者禁用 / 证候不符不得使用。
- 交互：节点可点选中（联动详情面板）；悬停高亮。

**右栏详情面板**：选中实体（如 人参/中药，绿点+标签）；字段：**别名**（园参、山参）、**说明**（传统补气类中药，个体使用需结合体质、证候和合并用药。）、**来源**（内置中医药教学演示数据（需专业审核））；底部图例：方剂● 中药● 证候● 功效● 禁忌(红)。

**候选审核 Tab**：展示待审核三元组（LLM 抽取 → 人工确认 → 发布）；来源统一标注「需专业审核」。

**验收**：① 力导向图正常渲染、点节点联动左列表与右详情；② 6 类节点配色与图例一致；③ 「候选审核」列表操作后状态更新。

1. **逐屏对照**：每个页面按本规格第二节逐字段与原始截图比对，差异记为缺陷。
