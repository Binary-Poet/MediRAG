### P0-1 登录页（`views/Login.vue` + `BlankLayout`）

> 版式参照 `docs/原项目前端展示图（部分）` 中的登录截图（居中悬浮卡片 + 左品牌区 + 右表单区）；
> 文案沿用本项目自身表述，不照抄参考图原文。

**布局**：页面浅绿渐变底 + 三个缓慢漂浮的模糊光斑（12s/15s/18s 异步循环，`prefers-reduced-motion` 下停用）；
居中一张悬浮卡片（约 1000×660px、圆角 24px）。
**卡片质感**：iOS 液态玻璃——高透底 `rgba(255,255,255,0.12)` + `backdrop-filter: blur(46px) saturate(180%) brightness(1.06)`，
配 1.5px 渐变折射描边（mask 挖空）与一道极淡的斜向扫光；光斑透过卡片形成流动色块。
卡片内部左右分栏——左品牌区（约 59%，半透明深绿玻璃 + 白字）＋右表单区（约 41%，高透白玻璃）。
**字体**：Claude 风格排版，**全站生效**（登录页与登录后所有页面、含图表 canvas 文字）——统一使用衬线体族
`theme.fontDisplay`：拉丁字形 `Source Serif 4`（≈ Copernicus，OFL 替代），中文字形 `Noto Serif SC`（思源宋体，OFL）。
三族字体自托管于 `web/public/fonts/`，声明见 `web/src/styles/fonts.css`：拉丁按整族引入（可变字体，单文件覆盖全字重）；
中文按 pyftsubset 子集化，**字符集覆盖五类来源**——界面文案、`data/` 语料与图谱、后端中文文案、文档术语、
jieba 高频汉字缓冲，共 3101 字，400/600 两个字重使用**完全相同的字符集**（各约 550KB）。
> 字符集必须覆盖得足够宽：页面上展示的实体名、会话标题等来自运行时的语料/图谱数据与用户输入，
> 一旦某些字不在子集内，就会回落系统宋体，出现"同一句话两种字体"的拼接。子集与数据同步更新：
> `cd web && python scripts/build-cjk-subset.py`（内置覆盖自检，缺字即退出非 0）。未收录生僻字回落系统衬线体
> （Songti SC / SimSun），不会出现方框。
**字重约束**：中文子集只发布 400/600，故界面**只用 400（正文）与 600（强调）**，不得出现 500/700——
否则同一串里拉丁取真 500/700、中文落到 400/600，字重不一致，与上条同属"拼接"。
Element Plus 默认主字重为 500，已在 `element-overrides.css` 收敛：`--el-font-weight-primary: 600`
（按钮/复选框/单选/链接均引用该变量），另逐个覆盖 EP 写死字重的选择器（tabs 项、collapse 头、
面包屑分隔符、select 选中项、descriptions 标题与带边框 label）；自有样式的 `.empty-title`、
`.detail-head strong` 亦显式声明 600。
**落地方式（三处覆盖，缺一不可）**：
① `main.ts` 把 `theme.fontDisplay` / `theme.fontSans` 注入根元素 CSS 变量 → `element-overrides.css` 里 `body` 与
`--el-font-family` 引用变量（Element Plus 组件只用 `var(--el-font-family)` 或 `font-family: inherit`，故覆盖这两处即全站生效）；
② 表单控件（button/input/select/textarea）在 CSS 中 `font-family: inherit` 拉回；
③ ECharts 的 canvas 文字不继承 CSS，由 `utils/echarts.ts` 注册 `medirag` 主题（`textStyle.fontFamily`），
两个图表页以 `init(dom, ECHARTS_THEME)` 初始化。
组件内如需覆盖（如装饰性引号）可用 `v-bind(theme.fontDisplay)`。`theme.fontSans`（DM Sans）保留备用，当前各页面均未使用。
商用字体 Copernicus / Styrene B 不可打包进仓库。

**左侧品牌区**（主色渐变，白字）：
- 顶部：叶子图标 + 品牌名「本草智问」
- 字距放大的英文标签：「INTELLIGENT TCM KNOWLEDGE CONSULTATION」
- 主标题（两行）：「中医药知识 / 智能问答平台」

- 4 条短横线要点（每条以 `—` 起头）：
  1. 三路混合检索：向量 + BM25 + 图谱，RRF 融合召回
  2. Cross-Encoder 精排，按证据相关度重排序

- 装饰：要点区左上/右下各一枚低透明度大引号
- 底部版权：「© 2026 本草智问 · 中医药智能问答平台」

**右侧登录表单区**：
- 字距放大的小标签：「BENCAO RAG PLATFORM」
- 标题：「欢迎登录」，其下 42×3px 主色短下划线
- 用户名输入框（下边框线性样式，用户图标，小标签「用户名」，placeholder=`请输入用户名`）
- 密码输入框（同上，锁图标，placeholder=`请输入密码`，带显示/隐藏切换）
- 行内校验错误（红字 + 圆形感叹号）：「请输入用户名」/「请输入密码」

**「立即注册」弹窗**（`el-dialog`，440px）：说明「注册后获得『知识用户』角色……如需更高权限请联系管理员」+
用户名（3–20 字符）/ 姓名（选填，不填用用户名）/ 密码（≥6 位）/ 确认密码四个字段，行内错误复用登录页 `.field-error` 样式。
前端先挡明显错误（用户名长度、密码长度、两次不一致），后端 `POST /api/auth/register` 再独立校验一次

否则任何人都能注册成管理员。注册成功直接返回 token，前端免二次登录进主页。

**「忘记密码？」弹窗**：系统未接入邮件/短信，无安全的自助找回路径，故不做假流程，只说明
「暂不支持自助找回密码，请联系系统管理员在『账户管理』中重置」。该提示是**可执行**的：
管理员在账户管理页可对指定账号重置密码（`PUT /api/users/{id}/password`，见 P2）。
- **演示账号**区：虚线分隔 + 居中字距标签「演示账号（点按自动填充）」；两张账号卡片（点击同时填充用户名与密码，右侧复制图标，hover 变主色）：
  - 管理员 `admin` / `admin123`
  - 知识用户 `user1` / `admin123`

**验收**：① 卡片居中悬浮与左右分栏比例同参考图；② 空值提交出现行内红字错误；③ 点演示账号卡片自动填充用户名+密码并可登录；
④ 登录成功进入主要布局；⑤ 点「立即注册」可注册新账号（获「知识用户」角色、注册成功自动登录），两次密码不一致有行内错误；

- **底部「清空会话」**（文字按钮，危险色）：**作用范围跟随当前筛选页**——停在「全部」时清全部（按钮文案「清空会话」，
  确认语「确定清空全部 N 个会话（其中 M 个已收藏）？该操作不可恢复。」）；停在「已收藏」时只清收藏
  （按钮文案「清空收藏」，确认语「确定清空 M 个收藏的会话？未收藏的 K 个会话会保留。该操作不可恢复。」）。
  条数取当前筛选页口径，保证弹窗数字与屏上列表一致；**确认语必须写明"删什么、留什么"**——只靠筛选页的位置/颜色
  区分删除范围太脆弱，看错一眼的代价是不可恢复的数据丢失。
  确认后：当次删掉的会话若包含当前打开的那个，问答区复位到空态；若不包含（收藏页清空时当前会话未被收藏），
  则保留当前对话不动。当前筛选页无会话时按钮置灰。放在列表底部而非顶部，与「+ 新对话」拉开距离以降低误点概率。
  接口侧 `favorite` 参数**必填**（缺参 422）：省略若回落成"清全部"，旧版前端在收藏页点清空会误删未收藏会话。

### P0-3 辨证问答 —— 回答态（`views/qa/Chat.vue`）

**回答正文结构**（自上而下）：
1. 流式回答正文（SSE `token` 追加）
2. **绿色安全提示框**（浅绿底 `#dcfce7` / 深绿字 `#166534`）：
   「注意：以上组成信息严格依据图谱事实，不包含加减变化或现代制剂衍变；实际临床应用须经中医师辨证后使用，不可自行套方。」
3. **图谱依据折叠块**：标题「图谱依据 (n)」+ 展开箭头，默认折叠；展开后逐条 `【图谱事实N】 实体 --关系--> 实体`，末行「文献来源：内置中医药教学演示数据（需专业审核）」
4. **证据来源折叠块**：标题「证据来源 (n)」+ 展开箭头，默认折叠；展开后每条 `[序号] 文献 篇名 —— 文献来源 · 章节 · 序号 N`
5. **检索溯源按钮**：「知识检索与图谱溯源」（置于两个折叠块之下）
6. **卡片底部操作行**：左侧「此回答有帮助吗？ 有用 / 无用」；右侧**撤回图标**（`RefreshLeft`，tooltip「撤回本轮提问，放回输入框重新编辑」）

**交互**：输入用 Enter 发送 / Shift+Enter 换行；思考中（尚未产出正文）不渲染底部操作行。

**撤回转义**（点底部撤回图标）：回到该提问「还没问」时的对话状态——**该轮及其之后的问答一并撤掉，之前的轮次保留**，
并把该提问**回填输入框**（回到"已输入未发送"）。只挖掉中间一轮会留下「第1轮 → 第3轮」的断档，
而后续轮次本就建立在该轮上下文之上；撤到一轮不剩（撤的是首轮）时连会话一并结束，前端解绑并刷新列表。
必须前后端同步删除：只删前端会让被撤轮次在重开会话时复活，并通过 `recent_history` 混入后续提问的多轮上下文。
**切换会话（新建/点选其他会话）时输入框清空**——草稿属于当前会话，避免误发到别的会话。

**验收**：① SSE 打字机；② 图谱事实与证据两个折叠块默认折叠、按钮在两者之下；③ 撤回按回滚语义执行（后续轮次一并消失、
之前的保留），提问回填输入框，重新打开该会话不回退；④ 切到其他会话后输入框为空；⑤ 安全框渲染与截图一致。

### P0-4 检索溯源弹窗（`TraceDialog.vue`）

**触发**：提问后默认弹开，SSE `step` 事件逐步点亮；可关闭（×）。

**结构**：
- 标题「知识检索与图谱溯源」
- 顶部**5 步流程条**：📝问句理解 → 🔍多路检索 → 🔄证据融合 → 📊相关性排序 → ✓生成回答（已完成=绿，当前=橙 `#f59e0b`，待执行=灰）
- 各步详情：
  - **步骤1 问句理解**：原始问题 vs 改写后查询（左右对比）。截图示例：`四君子汤由哪些中药组成？` → `四君子汤的中药组成成分`
  - **步骤2-3 多路检索 / 证据融合**：4 张数字卡 —— 向量检索（语义相似度）0 / 中医药图谱（1个命中实体）22 / 关键词检索（关键词匹配）0 / → 证据融合（互惠排名融合）0
  - **步骤4 相关性精排**：N 条证据进入回答上下文 + 状态徽章「证据充分，正常生成」（绿色胶囊）
- （扩充，符合合并方案）「自反思」触发时显示一轮「重查」提示；Agent 调用了哪些工具展示在该步数字卡/说明内。

**验收**：① 5 步依次点亮；② 四君子汤问题命中面板复现「22/0/0」；③ SSE 事件到哪步点亮到哪步。
