### P0-1 登录页（`views/Login.vue` + `BlankLayout`）

> 版式参照 `docs/原项目前端展示图（部分）` 中的登录截图（居中悬浮卡片 + 左品牌区 + 右表单区）；
> 文案沿用本项目自身表述，不照抄参考图原文。

**布局**：页面浅绿渐变底 + 三个缓慢漂浮的模糊光斑（12s/15s/18s 异步循环，`prefers-reduced-motion` 下停用）；
居中一张悬浮卡片（约 1000×660px、圆角 24px）。
**卡片质感**：iOS 液态玻璃——高透底 `rgba(255,255,255,0.12)` + `backdrop-filter: blur(46px) saturate(180%) brightness(1.06)`，
配 1.5px 渐变折射描边（mask 挖空）与一道极淡的斜向扫光；光斑透过卡片形成流动色块。
卡片内部左右分栏——左品牌区（约 59%，半透明深绿玻璃 + 白字）＋右表单区（约 41%，高透白玻璃）。
**字体**：Claude 风格排版——**整页所有文字**（标题、描述、要点、表单标签、按钮、提示语、版权、演示账号）
统一使用衬线体族 `theme.fontDisplay`：拉丁字形 `Source Serif 4`（≈ Copernicus，OFL 替代），
中文字形 `Noto Serif SC`（思源宋体，OFL）。三族字体自托管于 `web/public/fonts/`，声明见 `web/src/styles/fonts.css`：
拉丁按整族引入（可变字体，单文件覆盖全字重），中文按前端实际用字做 pyftsubset 子集（400 字重 132KB 覆盖全部界面用字、
600 字重 23KB 只含标题用字，避免大字号合成加粗）；未收录汉字回落系统衬线体（Songti SC / SimSun），不会出现方框。
Element Plus 组件不继承外层字体，用 `:deep()` 统一拉回。`theme.fontSans`（DM Sans）保留备用，登录页当前未使用。
商用字体 Copernicus / Styrene B 不可打包进仓库。

**左侧品牌区**（主色渐变，白字）：

### P0-4 检索溯源弹窗（`TraceDialog.vue`）

**触发**：提问后默认弹开，SSE `step` 事件逐步点亮；可关闭（×）。

**结构**：
- 标题「知识检索与图谱溯源」
- 顶部**5 步流程条**：📝问句理解 → 🔍多路检索 → 🔄证据融合 → 📊相关性排序 → ✓生成回答（已完成=绿，当前=橙 `#f59e0b`，待执行=灰）
- 各步详情：
  - **步骤1 问句理解**：原始问题 vs 改写后查询（左右对比）。截图示例：`四君子汤由哪些中药组成？` → `四君子汤的中药组成成分`
  - **步骤2-3 多路检索 / 证据融合**：4 张数字卡 —— 向量检索（语义相似度）0 / 中医药图谱（1个命中实体）22 / 关键词检索（关键词匹配）0 / → 证据融合（互惠排名融合）0
  - **步骤4 相关性精排**：N 条证据进入回答上下文 + 状态徽章「证据充分，正常生成」（绿色胶囊）
- （扩充，符合合并方案）「自反思」触发时显示一轮「重查」提示；Agent 调用了哪些工具展示在该步数字卡/说明内。

**验收**：① 5 步依次点亮；② 四君子汤问题命中面板复现「22/0/0」；③ SSE 事件到哪步点亮到哪步。
