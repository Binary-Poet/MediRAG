完整前后端源码｜多路检索｜知识图谱｜来源可追溯
✅ 完整 RAG 问答流水线
查询改写 → 向量召回 → 关键词召回 → 图谱检索 → RRF 融合 → 重排序 → Prompt 组装 → SSE 流式生成。
✅ 三路联合检索
Milvus 负责语义向量检索，关键词检索捕捉中医药专有名词，Neo4j 补充药材、方剂、证候、功效和禁忌关系。
✅ RRF 融合 + gte-rerank 精排
多路结果统一去重融合，再通过重排序模型筛选高相关证据，准确性优于单路向量检索。
✅ GraphRAG 核心亮点
文献切片存入 Milvus，审核后的实体关系存入 Neo4j，实现“原文证据 + 图谱事实”联合生成。
✅ 回答来源可追溯
每次回答可展示文档名称、章节、页码、原文片段和完整检索过程，回答依据可以核查。
✅ 医疗安全兜底
检索置信度不足时明确提示知识库未匹配；命中紧急症状时触发就医提醒，避免无依据编造。
✅ 多格式知识库自动入库
支持 PDF、Word、Excel、PPT、Markdown、CSV、JSON、XML、YAML、HTML 等格式，自动解析、切片、向量化并写入 Milvus。
✅ SSE 实时流式回复
前端实时展示检索进度、回答内容和引用来源，提供类似 ChatGPT 的打字机交互体验。
技术栈：Spring Boot 3 + Vue 3 + LangChain4j + Milvus + Neo4j + Redis + MySQL
